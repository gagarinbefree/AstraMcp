54 детали размещены на 11 физических листах, ещё две ожидаемо не размещены. Проверены координаты всех размещённых деталей и 95 отрезков резов. Индивидуальные `geometry.json` содержат измерения и покрытие координатами.

Общий отчёт: [report.json](report.json). Проверка последовательности процессов, сохранности исходников и SHA-256 результатов: [verification.json](verification.json). Подробное описание: [native-verification.md](../../../../docs/native-verification.md).
