# Проверка фонового запуска, 01.11.2026

Астра запускается на отдельном невидимом рабочем столе Windows. По умолчанию
`Astra:RunInBackground=true`; для диагностики можно выбрать `false`.
Приложение по-прежнему использует установленную Астру и профиль текущего
пользователя Windows. Активный рабочий стол не переключается.

## Автоматические проверки

Все 82 теста прошли без ошибок и пропусков. Сохранены этапы TDD:
`.cache/tdd/24-background-red.trx` и `.cache/tdd/24-background-green.trx`.
Полный прогон находится в `.cache/verification/tests.trx`.

Дополнительно воспроизведён сбой очистки логов при запуске постороннего процесса:
`.cache/tdd/26-inherited-handles-red.trx`. Родительские копии наследуемых
дескрипторов теперь закрываются сразу после CreateProcess, до callback и ожидания.
Для файлов разрешено удаление при открытом дескрипторе: параллельный legacy запуск
другого процесса не блокирует очистку завершённого задания. Полный прогон
Release после исправления: `.cache/tdd/26-inherited-handles-green.trx`, 82 теста.

Отдельный тестовый процесс самостоятельно определяет свой фактический desktop,
создаёт на нём видимое окно и сообщает результат. Тест проверяет отличие этого
desktop от рабочего стола родителя и освобождение объекта после выхода.
Создание тестового окна разрешено только на desktop с уникальным префиксом
`AstraMcp-`, поэтому падающий тест изоляции не показывает его пользователю.

Проверены также видимый режим, отмена фонового процесса, сохранение постороннего
процесса, ошибка запуска и ошибка сохранения PID до возобновления процесса.
Аргумент с пробелами, кириллицей и символами `&`/скобками передаётся как единый
путь без запуска командной оболочки. stdout и stderr записываются отдельно.

## Реальная Астра через MCP

Официальный .NET MCP-клиент отправил восемь заказов в опубликованный Windows x86
сервер версии 0.1.0. Астра 5.8.0.0 рассчитала все восемь с включённым фоновым
режимом. Для каждого задания создан отдельный desktop, имя которого сохранено
в `execution.log`, и отдельный PID Астры. Расчёты выполнялись последовательно.

Получены 11 физических листов, 54 размещённые детали и две ожидаемые
неразмещённые детали. Независимая проверка геометрии прошла для всех 54 деталей
и 95 отрезков резов. Это подтверждает работу экспорта и расчёта в выбранном
режиме; оптимальность и полная технологическая последовательность резов не
доказываются.

Файлы: [новый фоновый прогон](../examples/batch/results/20261101-151932-af45a129/README.md).
XML экспорта сохранены без изменения байтов. Настройки профиля Астры при этом
прогоне не менялись. Видимые окна на пользовательском рабочем столе не создаются
нашим способом запуска; автоматической подмены режима при ошибке нет.
