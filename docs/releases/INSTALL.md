# Astra MCP для Windows x86

Документация и примеры: https://github.com/gagarinbefree/AstraMcp

1. Распакуйте архив в доступный для записи каталог, например `C:\Tools\AstraMcp`.
   В архив включён runtime .NET. Node.js и SDK для запуска не требуются.
2. Установите Астру отдельно и проверьте `Astra.ExecutablePath` в `config.json`.
   В Астре настройте обработку параметров командной строки при запуске и экспорт
   XML при выходе с именем `*.xml`. Завершите ручную работу и закройте Астру.
3. В PowerShell 7 из каталога распакованного приложения выполните:

   ```powershell
   .\scripts\configure-astra-profile.ps1 -ConfigurationFile config.json
   ```

   Скрипт настраивает проверенный legacy-профиль Астры в реестре текущего
   пользователя и сохраняет прежние значения в `.cache/profile-configuration`.
   Подробная настройка других версий описана в README репозитория.
4. После настройки установите `Astra.ProfileReady=true`. По умолчанию включено
   `RunInBackground=true`; для диагностики можно выбрать `false`.
5. Укажите в своём клиенте MCP абсолютные пути к EXE и конфигурации:

   ```json
   {
     "mcpServers": {
       "astra": {
         "command": "C:\\Tools\\AstraMcp\\AstraMcp.exe",
         "args": ["--config", "C:\\Tools\\AstraMcp\\config.json"]
       }
     }
   }
   ```

Перед каждым расчётом адаптер завершает существующие процессы настроенной Астры
по PID. Несохранённый заказ в таком процессе теряется. Используйте выделенный
профиль и не совмещайте ручную работу с расчётами агента в том же приложении.

Фоновый режим использует отдельный невидимый desktop Windows. Астра остаётся
GUI-приложением в пользовательской сессии, а её блокирующие диалоги могут
привести к таймауту. Сервер записывает статусы, исходники, XML результатов и логи
в каталог `.data` рядом с конфигурацией.
